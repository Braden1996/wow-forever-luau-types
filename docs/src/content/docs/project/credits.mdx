## Sources of the definitions

| Source                                                                                                     | Licence                   | Used for                                                                                               |
| ---------------------------------------------------------------------------------------------------------- | ------------------------- | ------------------------------------------------------------------------------------------------------ |
| [Ketho/vscode-wow-api](https://github.com/Ketho/vscode-wow-api), © Ketho                                   | MIT                       | LuaCATS annotations: types for globals the documentation omits, FrameXML mixins and Lua extensions     |
| [warcraft.wiki.gg](https://warcraft.wiki.gg)                                                               | via the annotations above | Much of the annotations' content is sourced from the wiki                                              |
| [Gethe/wow-ui-source](https://github.com/Gethe/wow-ui-source) (`forever` branch)                           | no licence file           | Blizzard's `Blizzard_APIDocumentationGenerated`: argument and result types, structures, event payloads |
| [Ketho/BlizzardInterfaceResources](https://github.com/Ketho/BlizzardInterfaceResources) (`forever` branch) | no licence file           | Dumps from the live client: which APIs, widgets, events and enums exist                                |

From the two sources without a licence file, only API names and documented types reach the output.
