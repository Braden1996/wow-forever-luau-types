Issues and pull requests are welcome, from one-line fixes to new converter rules. This page summarises
[CONTRIBUTING.md](https://github.com/Braden1996/wow-forever-luau-types/blob/main/CONTRIBUTING.md), which is the
authoritative version.

## Where does the fix belong?

| Problem | Where to fix it |
| --- | --- |
| A wrong type for a documented C API (most `C_*` functions, widget methods, event payloads) | Blizzard's documentation is authoritative. If it is wrong, add a narrow rule in `generator/` |
| A wrong or missing type for an undocumented global, FrameXML mixin or Lua extension | Upstream annotations: [Ketho/vscode-wow-api](https://github.com/Ketho/vscode-wow-api) |
| An API Forever has but the definitions lack, or the reverse | The client dump: [Ketho/BlizzardInterfaceResources](https://github.com/Ketho/BlizzardInterfaceResources) (`forever` branch) |
| A construct converted wrongly, or invalid Luau | This repository: `generator/`, with a snapshot case |
| A FrameXML table or frame global that no source declares | This repository: `supplements/framexml.d.luau` |
| A false or missed error in real addon code | This repository: a sample under `tests/`, then fix the cause |

<Aside type="caution">
  Never edit generated files by hand. `definitions/` and `.github/banner.svg` come from `lune run scripts/generate`,
  and CI fails if they differ from a fresh generation.
</Aside>

## Setup

1. Install [mise](https://mise.jdx.dev).
2. Run `mise install`. It installs the pinned tools (versions in `mise.toml`, checksums in `mise.lock`).
3. Run `mise exec -- lune setup` to write Lune's type definitions, so the generator type-checks in your editor.
   Enable luau-lsp's new solver.

## The checks

CI runs every check; run them before you push.

```sh
mise exec -- lune run scripts/generate -- --check   # generated files match upstream.toml
mise exec -- lune run scripts/test                  # samples: zero errors in tests/pass, exact errors in tests/fail
mise exec -- lune run scripts/snapshot              # converter snapshot cases
mise exec -- stylua --check .
mise exec -- selene .
mise exec -- typos
mise exec -- actionlint
```

## Tests

- **`tests/pass/<addon>/`** is a sample addon. Every `.luau` file must type-check with zero diagnostics.
- **`tests/fail/*.luau`** are negative fixtures. Each must produce exactly the diagnostics in its `.expected` file.
  After an intended change, run `lune run scripts/test -- --update` and review the diff.
- **`tests/snapshots/<case>/`** are converter cases: small inputs in the upstream formats and the expected output.
  Refresh with `lune run scripts/snapshot -- --update`.

## This documentation site

The site lives in [`docs/`](https://github.com/Braden1996/wow-forever-luau-types/tree/main/docs). It is an
[Astro](https://astro.build) and [Starlight](https://starlight.astro.build) project, built to static files for
GitHub Pages. The API reference, search index and hover cards are generated at build time from
`definitions/wow-forever.d.luau` and `definitions/coverage.json`, so they never drift from a release.

- Guides like this page are MDX files in `docs/src/content/docs/`.
- Bun is the package manager, pinned through mise like the other tools.
- Its checks run in CI on every pull request: a strict TypeScript type check, oxlint, an oxfmt format check, the
  unit tests and a full build. Pushes to `main` deploy the site.

To work on it locally:

```sh
cd docs
mise exec -- bun install
mise exec -- bun run dev
```

## Pull requests

- One concern per pull request.
- Title: `type(scope): summary`, checked by CI. Types: feat, fix, perf, refactor, test, docs, build, ci, chore,
  style, revert. Use the `docs` scope for this site.
- Note user-visible changes in `CHANGELOG.md` under "Unreleased".
