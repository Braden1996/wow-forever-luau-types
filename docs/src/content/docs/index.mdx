## Why

The game reports a typo in an event name, a missing nil check or a removed global only when the code runs, often in
the middle of play. `wow-forever.d.luau` is one definitions file for the
[luau-lsp](https://github.com/JohnnyMorganz/luau-lsp) language server and type checker. With it, your editor and
your CI report those mistakes as you type:

```luau
--!strict
local frame = CreateFrame("Frame")            -- a Frame; CreateFrame("Button") is a Button
frame:RegisterEvent("PLAYER_LOGN")             -- error: not an event the client sends
frame:SetScript("OnClick", onClick)            -- error: a plain Frame has no OnClick script
frame:SetPoint("CENTRE")                       -- error: not an anchor point
local info = C_QuestLog.GetInfo(1)
print(info.title)                              -- error: info may be nil
GetQuestLogTitle(1)                            -- error: Forever replaced it with C_QuestLog
```

The definitions follow the WoW: Forever client (1.60.1, interface 16001). Forever runs the modern client with
Classic content, so neither the retail nor the Classic Era API is right for it: <Sym fn="C_QuestLog.GetInfo" />
exists there, `GetQuestLogTitle` does not.

## What is inside

<CardGrid>
  <Card title="C API, 83% typed" icon="approve-check">
    5,757 of the client's 6,904 native functions (global and `C_*`) have argument and result types, mostly from
    Blizzard's own API documentation. The rest are declared, with `unknown` results.
  </Card>
  <Card title="Widgets in their real hierarchy" icon="puzzle">
    58 widget types as extern types, from <Sym type="FrameScriptObject" /> down to <Sym type="CheckButton" />. 1,720 of
    1,733 methods typed. Script names are per widget.
  </Card>
  <Card title="Every event, with its payload" icon="rocket">
    1,816 events form a closed union, and `EventHandler<E>` gives each handler its documented payload, such as
    <Sym event="PLAYER_LEVEL_UP" />.
  </Card>
  <Card title="Structures and enums" icon="list-format">
    840 structures and mixins (some derived as `Base & { ... }`) and 954 enums from the client, with nil-safety on
    every optional field.
  </Card>
</CardGrid>

Every API the client has is listed as typed, untyped or excluded, with a reason. CI fails if a typed API loses its
types. See [Coverage](/wow-forever-luau-types/coverage/) for the full tables.
