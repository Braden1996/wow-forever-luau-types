# Security

This repository publishes type definitions and the tooling that generates them; it runs nothing in the game. The
parts with a security surface are the generator (it fetches and parses upstream repositories) and the GitHub
workflows.

## Reporting a vulnerability

Report it privately through
[GitHub's private vulnerability reporting](https://github.com/Braden1996/wow-forever-luau-types/security/advisories/new),
not in a public issue. You will get a reply within a week. Fixes are released as a patch version and credited in
the changelog unless you ask otherwise.

## Supported versions

Only the latest release receives fixes.
